Tutorials:

## Create a Custom Track
Modify your scene based on MapExample.scene, for example saved as YourTrack.scene

## UGC Map Manager
Open the manager window with menu:
Tools -> UGC Map Manager

![Step 1 - Login Account](/docs/images/login.jpg)

After login you will see:
(If you have no maps yet, the list will be empty)
![Step 2 - UGC Map Manager](/docs/images/manager.jpg)

If the opened scene is not linked to a map yet, you can create a new map with the button "Create New Map".
![Step 3 - Create Track](/docs/images/create_track.jpg)

After that the edit window for the new map will open:
![Step 4 - Edit Track](/docs/images/edit.jpg)
You need to click "Save" button after text editing, but change image will automatically be saved when you select a new image.
The important thing is to click "Build & Upload", that means build the scene and upload the map to the server.
"Create Version" is also important, if a map is already published, you need to create a new version first, then edit or build the new files.

After building and uploading is done, you can publish the track with the button "Publish" in the manager window.
![Step 5 - Publish Track](/docs/images/publish.jpg)

After publishing, the track will be waiting for review by the FR Legends team.

## Test Map Draft
Note: You need to test the uploaded map before publishing, you can open FR Legends on mobile and goto "Custom Tracks", select "My Drafts":
Find the uploaded track click it open the details, and click "Play" to play it in the game, ensure it runs well, and then back to the manager to publish it.
If you found any issues, you can fix them in the scene, then build & upload again to update the draft.
![Step 6 - Test Track](/docs/images/drafts.jpg)

Once the track is approved by the FR Legends team, it will be available in the game for all players to download and play.

You may need to click "Refresh List" button in the manager to see the updated status after review.
